# 여행 정보

여행을 준비할 때 필요한 내용을 빠짐없이 확인할 수 있는 페이지입니다. 아래 항목을 여행지에 맞게 채우면 하나의 여행 가이드가 완성됩니다.

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 여행지 | 도시 또는 지역 이름 |
| 여행 기간 | 3박 4일 |
| 추천 시기 | 날씨와 성수기를 고려한 시기 |
| 언어 | 현지 언어 / 영어 사용 가능 여부 |
| 통화 | 현지 통화와 대략적인 환율 |
| 시차 | 한국과의 시차 |

!!! note "출발 전 확인"
    여권 유효기간, 비자·입국 조건, 여행자 보험과 최신 안전 공지는 반드시 공식 기관에서 다시 확인하세요.

## 추천 일정

=== "1일 차"

    **도착과 동네 적응**

    - 공항에서 숙소로 이동
    - 숙소 주변 산책
    - 현지 음식으로 첫 저녁

=== "2일 차"

    **대표 명소 둘러보기**

    - 오전: 인기 명소 방문
    - 오후: 박물관 또는 전시 관람
    - 저녁: 야경 명소 산책

=== "3일 차"

    **로컬처럼 여행하기**

    - 현지 시장 또는 카페 거리
    - 근교 반나절 여행
    - 기념품 쇼핑

=== "4일 차"

    **여유롭게 마무리**

    - 체크아웃 및 짐 보관
    - 놓친 장소 방문
    - 공항 이동

## 교통

### 공항에서 시내까지

| 이동 수단 | 예상 시간 | 비용 | 특징 |
| --- | ---: | ---: | --- |
| 공항철도 | 약 40분 | — | 빠르고 정시성이 높음 |
| 공항버스 | 약 60분 | — | 숙소 가까이 이동 가능 |
| 택시 | 약 45분 | — | 짐이 많거나 여러 명일 때 편리 |

### 현지 이동

- 교통카드 또는 모바일 승차권 준비
- 막차 시간과 환승 규칙 확인
- 도보 이동이 많은 날은 편한 신발 착용
- 지도 앱에 주요 장소와 숙소를 미리 저장

## 숙소 고르기

지역을 정할 때는 관광지와의 거리뿐 아니라 **대중교통, 늦은 시간의 안전, 주변 편의시설**도 함께 확인하세요.

1. 지도에서 방문할 장소를 모두 표시합니다.
2. 장소가 가장 많이 모인 지역을 찾습니다.
3. 공항과 기차역으로 이동하기 편한지 확인합니다.
4. 최근 후기를 중심으로 소음과 청결 상태를 살펴봅니다.

## 준비물 체크리스트

- [ ] 여권과 비자·입국 서류
- [ ] 항공권과 숙소 예약 확인서
- [ ] 여행자 보험 증서
- [ ] 현금, 해외 결제 카드
- [ ] 유심·eSIM 또는 로밍
- [ ] 충전기, 보조 배터리, 변환 플러그
- [ ] 상비약과 개인 의약품
- [ ] 날씨에 맞는 옷과 편한 신발

## 유용한 팁

??? question "인터넷은 어떻게 준비하나요?"

    짧은 여행이라면 eSIM이 간편합니다. 휴대전화의 eSIM 지원 여부와 현지 통신망, 데이터 제공량을 비교하세요.

??? question "환전은 얼마나 해야 하나요?"

    카드 결제 비중을 먼저 확인한 뒤 교통, 시장, 소규모 상점에서 쓸 최소한의 현금을 준비하세요.

??? question "일정이 너무 빡빡하지 않은지 확인하려면?"

    하루의 핵심 장소를 두세 곳으로 제한하고, 장소 사이 이동 시간에 20% 정도의 여유를 더하세요.

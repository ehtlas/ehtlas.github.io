# 싱가포르 대중교통

MRT와 버스가 잘 갖춰져 있어 대중교통만으로 대부분의 관광지를 이동할 수 있습니다.

## 💳 신용카드 / Apple Pay

싱가포르의 MRT와 버스는 **거리비례 요금제(Distance Fares)**를 사용한다.

별도의 교통카드를 구입하지 않고 해외 발급 컨택리스 신용·체크카드를 MRT 개찰구와 버스 단말기에 직접 태그하여 이용할 수 있다.

Apple Pay, Google Pay, Samsung Pay 등의 모바일 결제도 지원한다.

- **지원 카드:** Visa / Mastercard / American Express 등
- **Apple Pay:** 사용 가능
- **Google Pay:** 사용 가능
- **Samsung Pay:** 사용 가능
- 별도의 교통카드 구입 및 충전 불필요
- 일반 성인 거리비례 요금 적용

### 요금

MRT / LRT 및 일반 버스는 이동 거리에 따라 요금이 결정된다.

| 이동 거리 | 일반 요금 |
| --- | ---: |
| 3.2km 이하 | S$1.28 |
| 3.3~4.2km | S$1.38 |
| 4.3~5.2km | S$1.49 |
| 5.3~6.2km | S$1.59 |
| 6.3~7.2km | S$1.68 |
| 7.3~8.2km | S$1.75 |
| 8.3~9.2km | S$1.82 |
| 9.3~10.2km | S$1.86 |
| 10.3~11.2km | S$1.90 |
| 15.3~16.2km | S$2.11 |
| 20.3~21.2km | S$2.30 |
| 30.3~31.2km | S$2.47 |
| 40.2km 초과 | S$2.57 |

일반적인 관광지 간 MRT 이동은 대체로 **1회 S$1~2대**라고 생각하면 편하다.

### 해외 발급 카드 수수료

해외에서 발급된 **Visa / Mastercard**를 대중교통 결제에 사용하면 **사용일당 S$0.60의 Foreign Bank Card Admin Fee**가 추가된다.

카드사에서 부과하는 해외결제 수수료는 별도일 수 있다.

### 이용 방법

**MRT**

입장 시 태그  
→ 목적지 이동  
→ 나올 때 동일한 결제수단 태그

**버스**

탑승 시 태그  
→ 하차 시 다시 태그

입장과 퇴장 시 반드시 **동일한 결제수단**을 사용한다.

예를 들어 Apple Pay로 입장했다면 나올 때도 Apple Pay를 사용한다. 같은 신용카드라도 `실물카드 → Apple Pay`처럼 섞어 사용하지 않는 것이 좋다.

## 🎫 Singapore Tourist Pass

관광객을 위한 **MRT / LRT / 일반 버스 무제한 이용권**이다.

| 기간 | 가격 |
| --- | ---: |
| 1일권 | S$17 |
| 2일권 | S$24 |
| 3일권 | S$29 |
| 4일권 | S$37 |
| 5일권 | S$45 |

### 특징

- 일반 MRT / LRT 무제한
- 일반 공공버스 무제한
- 별도 충전 없이 이용 가능
- 여러 날짜 패스는 **연속된 날짜**에 사용
- 24시간 단위가 아니라 **첫 사용일부터 해당일 대중교통 운행 종료까지를 1일**로 계산

### 포함되지 않는 교통

일부 프리미엄·특수 교통수단은 무제한 이용 대상에서 제외된다.

- Sentosa Express
- RWS8
- Express Bus
- 일부 Premium / Private Bus

따라서 **센토사섬 내부 교통까지 모두 포함되는 패스는 아니다.**

## 💡 교통수단 선택

| 구분 | 신용카드 / Apple Pay | Singapore Tourist Pass |
| --- | --- | --- |
| 결제 방식 | 이용할 때마다 결제 | 정액 무제한 |
| 1회 요금 | 약 S$1.28~S$2.57 | - |
| 해외카드 수수료 | Visa/Mastercard S$0.60/일 | 없음 |
| 충전 | 필요 없음 | 필요 없음 |
| MRT / LRT | O | O |
| 일반 버스 | O | O |
| Sentosa Express | 별도 결제 | 별도 결제 |
| 장점 | 간편하고 사용한 만큼 결제 | 대중교통을 많이 탈수록 유리 |
| 추천 | **일반적인 관광 일정** | **하루 이동 횟수가 많은 일정** |

일반적인 싱가포르 관광 일정이라면 **신용카드 / Apple Pay가 가장 간편하다.**

MRT와 버스의 1회 요금 자체가 비교적 저렴하기 때문에 이동 횟수가 많지 않다면 **Singapore Tourist Pass보다 실제 사용한 만큼 결제하는 방식이 유리할 수 있다.**
